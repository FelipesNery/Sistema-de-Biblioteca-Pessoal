# Sistema de Biblioteca Pessoal
Esse é um sistema criado em C na disciplina de lógica e linguagem de programação do curso de Análise e Desenvolvimento de Software.

Durante uma aula sobre linguagem C, me deparei com a função DO WHILE. Depois que vi seu funcionamento lembrei que minha esposa tinha pedido se eu conseguia fazer um sistema para ela lembrar quais livros ela tem. 

Sendo assim, com essa função pude criar este sistema que pode ser alimentado com até 100 livros. 

OBS: estou aprendendo novas possibilidades para melhorar esse sistema e melhorar também a parte visual.
